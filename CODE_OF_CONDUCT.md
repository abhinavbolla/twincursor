# Code of conduct

TwinCursor follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in issues, pull requests, discussions and anywhere else you represent the project.

In short: be kind, assume good intent, and critique the work rather than the person. Harassment,
personal attacks and publishing someone's private information aren't welcome here.

## Reporting a problem

Report anything that makes you feel unsafe or unwelcome through the project's
[private report form](https://github.com/abhinavbolla/twincursor/security/advisories/new). Start
the title with "Conduct". Only maintainers can see it, and the form works for any GitHub account.

We'll reply within 7 days and keep your report confidential. If the report is about a maintainer,
use [GitHub's abuse form](https://github.com/contact/report-abuse) instead.
