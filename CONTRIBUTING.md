# Contributing to TwinCursor

Thanks for helping! A few ground rules:

1. **Clean room.** Do not copy code from other pair-programming apps (for example Hopp or
   Tuple), even open-source ones. Ideas from public blog posts and talks are fine; write your own implementation.
2. **Measure media changes.** PRs that touch capture, encoding, transport or rendering must
   include before and after latency numbers (see [Architecture](docs/ARCHITECTURE.md#measuring-latency)).
3. **Small PRs**, Conventional Commit messages, and `cargo fmt` + `cargo clippy` clean.
4. By contributing, you agree your contribution is licensed under [AGPL-3.0](LICENSE).

Start with [docs/ROADMAP.md](docs/ROADMAP.md) and pick an unchecked item from the current milestone.
